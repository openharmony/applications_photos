模块介绍

Photo Picker 模块是一个用于图片选择的工具，支持从本地相册或相机中选择图片，并提供预览、多选等功能。该模块旨在为开发者提供一个简单易用的图片选择解决方案，适用于各种需要处理图片的应用场景。

----------------------------------------


功能特性

· 支持从本地相册选择图片
· 支持相机拍照功能（部分平台支持）
· 支持多选图片
· 提供图片预览功能
· 支持滑动勾选图片
· 支持设置最大选择数量
